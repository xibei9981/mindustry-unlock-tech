# 解锁全科技

从用户提供的“解锁科技(1).zip”整理出的 Mindustry 脚本模组。原配置署名：**I hope...**；版本 1.0，最低游戏版本 136。

## 游戏内导入

在“模组 → 导入模组 → 从 GitHub 导入”中填写：

```text
xibei9981/mindustry-unlock-tech
```

完整地址：https://github.com/xibei9981/mindustry-unlock-tech

导入后按提示重启游戏。脚本会解锁已加载内容中的科技；这会改变研究进度，使用前可导出存档备份。

## 整理说明

原压缩包的 `scripts/` 目录项存在重叠条目错误；`mod.json` 和 `scripts/main.js` 均能完整读取。本仓库保留这两个文件的原始字节，不修改解锁逻辑，通过 GitHub 重新生成正常的导入压缩包。
